# SectionMarks — отметки разрезов на продольном профиле

## Состояние (10 ноября 2026)

Написано и **собирается**; в чертеже **не проверено** — ни одна команда.

Отметка = блок с названием сечения + две вертикальные чёрточки (в верхней и
нижней части вида профиля) со стрелками, приходящими к их серединам.

Привязка — к **линии выборки** (сечению в плане) и к **виду профиля**. Пикет
отметки — там, где линия выборки пересекает **трассу вида профиля**, поэтому
на виде можно показывать и сечения соседней трассы, которые эту трассу
пересекают. Раньше (22 октября) отметка привязывалась к виду сечения и брала
пикет самой линии — только для собственной трассы; записи того формата читаются
и работают по-прежнему.

| Команда | Что делает |
|---------|-----------|
| `RW_SECTIONMARKS` | «Вынести поперечные сечения»: выбрать вид профиля, затем сечения — **Указать** (линии выборки мышью в плане), **Группа** (окно с флажками по группам линий выборки всех трасс) или **Своей** (группы трассы вида). Для каждой линии ищется пересечение с трассой вида, по его пикету ставится отметка. Не пересекающие или лежащие за краем вида пропускаются, их имена печатаются |
| `RW_SECTIONMARKEDIT` | «Редактировать отображение»: меню **Блок** (выбрать блок из чертежа, ко всем отметкам и по умолчанию), **Развернуть** (стрелки отметки), **Удалить** (отметку по любой её части или все отметки вида профиля), **Обновить** (вернуть стёртое, убрать осиротевшие); Enter — выход |
| `RW_SECTIONMARKDIAG` | состояние оверрула, счётчики, последняя ошибка (не удалять) |

Блок по умолчанию — `RW_sectionOnProfile`. Если его нет в чертеже, создаётся
заготовка (кружок с атрибутом `NAME`). Название сечения (имя линии выборки)
пишется в атрибут `NAME`/`НАЗВАНИЕ`/`ИМЯ`/`СЕЧЕНИЕ`/`SECTION`…, а если такого
нет — в первый неконстантный атрибут блока. Всё нарисованное — на слое
`RW_SECTION_MARK`.

## Направление стрелок

Сечение Civil 3D смотрит вперёд по пикетажу **своей** трассы. На трассе вида
это переводится по касательным в точке пересечения: совпадает с ходом пикетажа
трассы вида — стрелка вперёд (вправо), против — назад. Для собственной трассы
всегда вперёд. Ручной «Развернуть» накладывается поверх этого.

## Связь

- линия выборки сдвинута → отметка встаёт на новый пикет пересечения; линия
  больше не пересекает трассу вида (или ушла за край вида) → нарисованное
  стирается, запись остаётся и ждёт возвращения линии;
- стёрта линия выборки, вид профиля, его трасса или сам блок → отметка
  удаляется целиком; (у записей первой версии — ещё и вид сечения);
- стёрта чёрточка или стрелка — рисуется заново;
- блок можно двигать по высоте (запоминается), по пикетажу он привязан;
- чёрточки двигаются ручками **только по вертикали**; высота запоминается
  как отметка в профиле и переживает смену масштаба вида.

## Устройство

`SectionMarkReactor` (по реактору на чертёж) только помечает изменения, а на
`CommandEnded`/`Idle` перестраивает под `LockDocument` — схема `BreakReactor`.
Чёрточки — служебные `Line` с XData `RW_SECTIONMARK`; ручки перехватывает
`SectionMarkGrips` (оверрул на `Line`, чужие отрезки уходят в `base`, вертикаль
получается отбрасыванием X-составляющей смещения). Модель — Xrecord в словаре
NOD `RW_SECTIONMARKS`, ключи `SM_<guid>`, ссылки — Handle.

Пересечение (`SectionCrossing`) ищется по смене знака смещения от трассы вдоль
линии выборки с уточнением делением пополам — без полилинейного двойника трассы.
Если у линии несколько пересечений с трассой, берётся первое по ходу линии.

Инициализация — из `BreakCommands` (в сборке одна точка входа).

## Допущения и ограничения

- Чёрточки — `Line`, не `Polyline`: ручки на них проверенным способом.
- Размер стрелки пропорционален длине чёрточки; масштаб блока — свойство
  вставки, правится в палитре.
- Новая линия выборки сама на профиле не появляется — повторить `RW_SECTIONMARKS`.
- Отметка привязана к одной линии выборки; при нескольких пересечениях с трассой
  вида нужен второй проход — не сделано.
