# Civil3D_ForRfRW

Инструменты Autodesk Civil 3D 2024 для проектирования **армогрунтовых подпорных
стен** (Reinforced Fill Retaining Wall). Два независимых проекта: плагин с набором
команд на C# и набор параметрических подсборок на VB.NET.

Интерфейс, комментарии и документация — на русском.

## Что внутри

| Папка | Что это | Язык |
|-------|---------|------|
| `Civil3D_commands/` | Плагин с командами: облицовка стены, ассоциативные разрывы коридора по профилю, поверхности коридора, ведомость материалов, наборы характеристик | C#, .NET Framework 4.8 |
| `RfRW_elements_kit_v0.4/` | Набор параметрических подсборок (subassemblies) для коридора: облицовочные элементы, геопанели, дренаж, основание, грунты | VB.NET |

### Плагин команд

Два основных модуля, у каждого свой подробный `README.md` — читать его первым:

- **`Civil3D_commands/FaceArr/`** — параметрическая облицовка стены.
  Массив блоков вдоль трассы с перевязкой, половинчатые блоки и замены по местам,
  правка границ мышью сразу в плане и в виде профиля.
  [Подробно](Civil3D_commands/FaceArr/README.md)
- **`Civil3D_commands/ProfCorrLink/`** — ассоциативные разрывы коридора.
  Участки коридора разводятся микроразрывом и становятся самостоятельными;
  граница переносится ручкой или командой с предпросмотром, ступень профиля
  и границы участков едут за ней.
  [Подробно](Civil3D_commands/ProfCorrLink/README.md)

Общее для обоих модулей — в `Civil3D_commands/Shared/`: перевод «пикет ↔ точка»
в плане и в виде профиля, работа со ссылками на объекты через Handle.

### Набор подсборок

Подсборки строятся по шаблону `SATemplate.vb` и подключаются к коридору
через палитры инструментов (`.atc`). Собранная библиотека распространяется
как пакет `.pkt`.

## Сборка

Плагин команд:

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" `
  Civil3D_commands\Civil3D_commands.csproj /t:Rebuild /p:Configuration=Debug
```

Ссылки на библиотеки Autodesk ищутся свойством `AcadDir` перебором обычных
путей установки. Своя папка задаётся явно — **обязательно со слешем в конце**:

```powershell
msbuild ... /p:AcadDir="X:\Program Files\Autodesk\AutoCAD 2024\"
```

Результат — `Civil3D_commands\bin\Debug\Civil3D_commands.dll`, загружается
в Civil 3D командой `NETLOAD`.

**Civil 3D удерживает загруженную сборку**: выгрузить .NET-библиотеку из сеанса
нельзя, поэтому перед пересборкой приложение нужно закрыть.

## Требования

- Autodesk Civil 3D 2024 (на .NET Framework; 2025 перешёл на .NET 8, там нужна
  пересборка под другой таргет);
- .NET Framework 4.8, MSBuild из Visual Studio 2022.

## Состояние

Рабочие инструменты, развиваются по ходу реальных задач. Проверка — только
в живом Civil 3D: команды интерактивны, а `accoreconsole` идёт без вертикали
Civil 3D, поэтому автотестов нет. Что подтверждено в чертеже, а что пока
только собирается, отмечено в README соответствующего модуля.
